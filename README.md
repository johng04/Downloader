Youtube converter capable of downloading playlists and indival videos in either .mp3 (audio) or .mp4 (video) formats.

<h2>Geting started</h2>

<p>The lastest version can be found here: https://github.com/johng04/Downloader/releases/latest
	
Simply download the .ZIP file and unzip the contents, open downloader.pyw to use the downloader.

Before running the downloader insure python is installed, which can be found here: https://www.python.org/downloads/</p>

First and infrequet use may lead to longer open times due to requred updates

<h3>Input fields </h3>

|Field|Format|Required|Default|Example|
|----|----|----|----|----|
|Youtube URL|Unlisted or public playlist or video URL|yes|N/A|https://www.youtube.com/playlist?list=PLyjqnQsvvnpIIhmuem71_Av3goBkEfxN8|
|Album name|String|no|Playlist name on youtube|Foo figters live - wembley 2007|
|Album artwork|File path to .jpg, .png, .jpeg |no|N/A|Downloader/Thumb.jpg|
|Download path|file path|no|Downloader folder|Downloader/|

Once a valid link has been entered, select a download option and wait for download to complete.
